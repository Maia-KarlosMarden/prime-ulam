Erasure codes — try them in your browser

Erasure codes at rate 0.80 and the same block size: Prime-Ulam (generated from a prime and 34 integers, no stored parity-check matrix) against two PEG codes. Everything below runs locally in JavaScript; it is a port of the Python reference implementation and is cross-checked against it. Paper and code: github.com/Maia-KarlosMarden/prime-ulam.

Settings

1. One erasure pattern

Each cell is one transmitted packet, in transmission order (rows of 80; every 4th packet is a parity). The decoder first peels the sparse equations, then solves what is left by Gaussian elimination.

2. Failure rate (Monte Carlo)

Exactly round(loss×n) packets are lost uniformly at random; failure = some symbol cannot be recovered (the paper's criterion). Compare with the paper's Section 4.1 (p=37, 150,000 patterns): 0 failures at 17.5%, 1.3×10-4 at 19%, 2.4% at 19.5%.
